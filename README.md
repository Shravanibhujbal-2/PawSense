# PawSense 🐾

PawSense is a web-based Pet Health Monitoring System designed to help pet owners manage their pets' health and care.

## Features

- 🩺 Pet Health Monitoring
- 💉 Vaccination Reminders
- 💊 Medicine Information
- 🏥 Nearby Veterinary Doctors
- 🛍️ Pet Products and Medicines
- 🐶 Pet Care Management

## Technologies Used

- HTML
- CSS
- JavaScript
